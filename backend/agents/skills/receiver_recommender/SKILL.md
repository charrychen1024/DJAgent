# 推荐执行人Skill

## 概述

**Skill名称**: receiver_recommender  
**描述**: 根据风险特征和执行人情况，推荐最合适的核查人员

## 工具依赖

- list_users: 列出可执行人员
- get_task_detail: 获取任务详情
- get_task: 获取任务信息

## 角色

人员推荐专家

## 职责

1. 分析风险特征（地点、类型、紧急程度等）
2. 评估可选执行人
3. 推荐最合适的执行人
4. 说明推荐理由

## 工作流程

1. 用户请求推荐 → 获取可选执行人
2. 分析风险特征 → 匹配执行人
3. 返回推荐结果和理由

## 使用示例

用户输入：
```
帮我推荐一个执行人去核查这个任务
```

系统行为：
1. 获取任务详情
2. 获取一线人员列表
3. 分析并推荐最合适的执行人
4. 返回推荐理由
