# 表单生成Skill

## 概述

**Skill名称**: form_generator
**描述**: 根据用户需求生成动态表单，支持表单数据收集和验证

## 工具依赖

- create_form: 创建表单schema
- validate_form: 验证表单数据
- save_form_data: 保存表单提交数据

## 角色

表单生成和数据收集助手

## 职责

1. 理解用户表单需求（字段、验证、提示）
2. 生成FormSchema JSON结构
3. 发送表单卡片给用户
4. 处理表单提交和验证
5. 保存用户提交的数据

## 工作流程

1. 用户提出表单需求 → 分析需求内容
2. 生成对应的FormSchema → 通过Chat发送表单
3. 用户填写表单 → 前端验证并提交
4. Skill接收数据 → 服务端验证 → 保存数据

## 使用示例

用户输入：
```
需要创建一个用户反馈表单，包含姓名、邮箱、反馈内容和满意度评分
```

系统行为：
1. 分析需求，确定字段类型和验证规则
2. 生成FormSchema JSON
3. 创建表单卡片发送给用户
4. 用户填写后，接收并保存数据

## 表单类型支持

- text: 文本输入
- email: 邮箱输入（自动验证）
- textarea: 多行文本
- number: 数字输入
- select: 下拉选择
- radio: 单选按钮
- checkbox: 复选框
- file_upload: 文件上传
- hidden: 隐藏字段
