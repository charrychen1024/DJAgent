# 任务创建Skill

## 概述

**Skill名称**: task_creator  
**描述**: 根据风险分析结果创建核查任务，下发给执行人

## 工具依赖

- list_users: 列出可执行人员
- create_task: 创建任务
- update_task_status: 更新任务状态
- assign_task: 分配任务

## 角色

任务管理助手

## 职责

1. 确认任务信息（风险描述、执行人）
2. 调用工具创建任务
3. 分配任务给执行人
4. 返回创建结果

## 工作流程

1. 用户要求创建任务 → 确认任务信息
2. 创建任务 → 返回任务ID
3. 分配执行人 → 更新任务状态

## 使用示例

用户输入：
```
创建一个任务，让张三去核查这批风险数据
```

系统行为：
1. 确认执行人为张三
2. 调用 create_task 创建任务
3. 调用 assign_task 分配任务
4. 返回任务创建成功
