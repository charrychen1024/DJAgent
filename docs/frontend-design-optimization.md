# DJAgent 前端界面设计优化方案

> 本文档记录 DJAgent 风控智能体系统的三个页面设计分析与优化思路。
> 分析时间：2026-03-13
> 分析工具：Claude Code frontend-design 技能

---

## 一、项目概述

DJAgent 是一个**风控数字员工管理系统**，包含两种角色工作空间：

| 角色 | 页面类型 | 描述 |
|------|----------|------|
| 业务负责人 | Web端智能体 | 三栏布局：风险数据 + AI对话 + 任务详情 |
| 一线员工 | IM端智能体 | 纯聊天界面，模拟微信/企业微信体验 |

---

## 二、登录页面（用户选择）

### 2.1 当前设计存在的问题

| 问题 | 详细说明 |
|------|----------|
| **缺乏品牌识别度** | 仅有简单的标题"🛡️ 风控数字员工"，无 Logo、无企业 VI 元素 |
| **交互体验单一** | 仅一个下拉选择框，无法体现登录仪式感 |
| **视觉层次不足** | 背景使用渐变色但缺乏焦点设计，用户视线分散 |
| **无身份说明** | 用户只能看到用户名+角色，无法快速理解不同角色的权限差异 |
| **响应式适配缺失** | 未针对移动端做优化 |

### 2.2 改进思路

- 添加企业 Logo/品牌元素
- 展示不同角色的职能说明卡片
- 增加记住我/自动登录选项
- 优化移动端适配

### 2.3 推荐设计风格

## 三、Web端智能体页面（业务负责人）

### 3.1 当前设计存在的问题

| 问题 | 详细说明 |
|------|----------|
| **三栏布局比例失衡** | 左侧风险数据(60%)过重，右侧详情栏(25%)内容稀疏，中间对话区(35%)偏窄 |
| **信息过载** | 风险数据表格字体仅 0.65rem，密集恐惧症式展示 |
| **视觉动线混乱** | 左侧数据表+任务列表混合，用户不知先看哪里 |
| **筛选功能粗糙** | 仅支持单字段筛选，无高级筛选/快速过滤 |
| **任务状态不直观** | 状态标签小(0.6rem)，颜色区分度低 |
| **响应式完全缺失** | 大屏专属，小屏完全不可用 |
| **空状态设计缺失** | 无数据时仅显示"暂无"文字 |

### 3.2 改进思路

**左侧栏（风险数据）**
- 改为数据卡片式展示，重要字段突出
- 支持风险等级可视化（红/黄/蓝警示条）
- 增加快速统计面板（高风险 X 条，本月新增 X 条）
- 引入智能筛选：最近 7 天、已处理/未处理

**中间栏（AI对话）**
- 加宽至 40-45% 视觉权重
- 对话气泡增加品牌元素（如 AI 头像）
- 支持消息引用（点击引用风险数据）
- 优化 Markdown 渲染样式

**右侧栏（任务详情）**
- 改为可折叠面板
- 时间轴展示任务进度
- 增加操作按钮（催办、转发、导出）

## 四、IM端智能体页面（一线员工）

> **重要说明**：这是一个**通讯工具界面**，模拟微信/企业微信的体验。所有任务信息都是通过对话消息推送的，不需要额外的顶部任务栏。

### 4.1 当前设计存在的问题

| 问题 | 详细说明 |
|------|----------|
| **缺乏微信/企微体验感** | 虽有"im-style"类名，但与网页版几乎无差异 |
| **对话气泡设计过时** | 圆角过大(16px)，无阴影，层次感弱 |
| **无头像** | 用户和 AI 消息无法快速区分 |
| **输入区域简陋** | 仅基础 textarea，无快捷回复入口 |
| **无时间分隔** | 消息时间不清晰 |

### 4.2 改进思路

**头像设计**
- 用户头像：绿色渐变圆形头像
- AI 头像：紫色渐变圆形头像

**对话气泡 - 微信风格**
- AI 消息：白色背景 + 左边 + 微阴影
- 用户消息：绿色渐变背景 + 右边 + 无阴影

**时间显示**
- 灰色胶囊分隔符，每隔一段时间显示

**底部输入框**
- 圆角胶囊形状
- 底部添加工具栏（上传文件等）

## 五、推荐统一设计风格

| 维度 | 推荐 |
|------|------|
| **整体调性** | 现代企业级 SaaS + 金融科技感 |
| **主色** | #1890ff（蓝） |
| **圆角** | 卡片 8px，气泡 12-16px，按钮 6px |
| **阴影** | 微阴影提升层次感 |
| **动效** | 按钮 hover、消息出现、加载骨架 |

## 六、改进优先级

### 登录页面

| 优先级 | 项目 | 改动量 |
|--------|------|--------|
| 🔴 高 | 添加 Logo/品牌元素 | 中 |
| 🔴 高 | 角色职能说明卡片 | 小 |
| 🟡 中 | 响应式适配 | 中 |

### Web端智能体

| 优先级 | 项目 | 改动量 |
|--------|------|--------|
| 🔴 高 | 风险数据看板 + 统计卡片 | 中 |
| 🔴 高 | 统一字体大小 (14-16px) | 小 |
| 🟡 中 | 三栏布局优化 | 中 |
| 🟡 中 | 筛选功能增强 | 中 |

### IM端智能体

| 优先级 | 项目 | 改动量 |
|--------|------|--------|
| 🔴 高 | 添加头像 | 小 |
| 🔴 高 | 气泡颜色/圆角 | 小 |
| 🟡 中 | 时间分隔显示 | 中 |
| 🟡 中 | 输入框美化 | 小 |

---

## 七、总结

当前界面功能完备但视觉较为朴素，适合向**现代 SaaS 风格**演进：

1. **短期**：调整字体大小、优化间距、统一配色
2. **中期**：引入卡片式设计，增加微交互
3. **长期**：考虑使用 Tailwind CSS 或 UI 组件库（Ant Design / shadcn/ui）
