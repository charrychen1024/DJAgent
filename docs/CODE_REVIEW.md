---

#### Bug 2: 任务状态流转不完整
**位置**: `backend/app_fastapi.py` + `backend/agents/tools/task_manager.py`

**问题描述**:
PRD要求的流转: `已创建 → 已下发 → 反馈中 → 反馈完成`

当前代码在 `task_manager.py` 第 163 行定义了"反馈中"状态：
```python
status: 新状态（已创建/已下发/反馈中/反馈完成/已超期）
```

但实际使用中，"反馈中"状态未被调用，状态直接从"已下发"跳到"反馈完成"。

**影响**: 任务状态跟踪不完整

**修复建议**: 
- 在 Staff 完成任务前，添加"反馈中"状态
- 前端 UI 需要展示"反馈中"状态

### 4.2 性能优化 🚀

#### 优化 4: 风险数据加载优化 (P1)
**位置**: `frontend/src/App.jsx` `fetchAllRiskData` 函数

**问题**: 循环请求 10 个风险数据文件，无并发

**当前实现**: 
```javascript
for (let i = 1; i <= 10; i++) {
  const response = await fetch(`${API_BASE}/risk-data/00${i}`)
  // ... 串行请求
}
```

**建议**: 使用 `Promise.all` 并发请求

```javascript
const fetchAllRiskData = async () => {
  const requests = Array.from({length: 10}, (_, i) => 
    fetch(`${API_BASE}/risk-data/00${i + 1}`)
  )
  const responses = await Promise.all(requests)
  const data = await Promise.all(responses.map(r => r.json()))
  // ...
}
```
