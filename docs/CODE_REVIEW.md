## 三、代码逻辑Bug审查

### 3.1 严重Bug 🔴

#### Bug 1: 文件上传参数名不匹配
**位置**: `frontend/src/App.jsx` 第 215 行 + `backend/app_fastapi.py` 第 180 行

**问题描述**:
```javascript
// frontend/src/App.jsx
pendingFiles.forEach(f => {
    formData.append('files', f.file, f.name)  // ❌ 发送 'files'
})

// backend/app_fastapi.py
for key in form.keys():
    if key.startswith("file_"):  # ❌ 期望 'file_'
```

**影响**: 文件上传功能可能失效

**修复方案**:
```javascript
// 方案1: 修改前端 (推荐)
pendingFiles.forEach((f, index) => {
    formData.append(`file_${index}`, f.file, f.name)
})
```

---

#### Bug 2: 会话配置缓存不更新
**位置**: `backend/agents/session_manager.py` 第 30 行

**问题描述**:
```python
_sessions: Dict[str, UnifiedAgent] = {}  # 缓存未自动更新
```

配置修改后需刷新页面才能生效，因为会话使用字典缓存。

**影响**: 修改配置后需重启服务或刷新页面

**修复方案**: 添加配置版本号，检测配置变化时自动刷新会话

---

## 四、代码优化建议

### 4.1 架构优化 🛠️

#### 优化 1: 统一工具架构
**建议**: 统一使用 Skills 或 MCP，避免双架构并存

当前问题:
- Manager 模式使用 MCP 服务器
- Staff 模式使用 Skills
- 两套工具注册机制并行

**建议方案**: 统一使用 Skills，删除 MCP 相关代码

---

#### 优化 2: 集中配置管理
**建议**: 创建统一的配置类

当前问题:
- 配置分散在 `config.py`, `mcp_server.py`, `session_manager.py`, `.env`

**建议方案**: 创建 `UnifiedConfig` 类集中管理

---

#### 优化 3: 添加单元测试
**建议**: 添加测试覆盖

当前问题:
- 无单元测试
- 无集成测试

**建议方案**:
- 创建 `backend/tests/` 目录
- 使用 pytest 框架
- 覆盖核心工具函数和 API 接口

---

### 4.2 性能优化 🚀

#### 优化 4: 风险数据加载优化
**位置**: `frontend/src/App.jsx` `fetchAllRiskData` 函数

**问题**: 循环请求 10 个风险数据文件，无并发

**建议**: 使用 `Promise.all` 并发请求

```javascript
const fetchAllRiskData = async () => {
  const requests = Array.from({length: 10}, (_, i) => 
    fetch(`${API_BASE}/risk-data/00${i + 1}`)
  )
  const responses = await Promise.all(requests)
  const data = await Promise.all(responses.map(r => r.json()))
  // ...
}
```
