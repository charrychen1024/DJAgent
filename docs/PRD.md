## 一、产品概述

### 1.1 产品名称
DJAgent - 风控智能助手

### 1.2 产品定位
面向物流/供应链场景的智能风险管控数字员工，通过AI Agent协助业务负责人和一线人员完成风险数据分析、任务分派、和反馈管理工作。

### 1.3 目标用户
- **业务负责人**: 风控部负责人、普通分析人员
- **一线人员**: 快递员、仓管员、质检员等一线操作人员

### 1.4 核心价值
- 提升风险识别效率 80%
- 减少人工核查成本 60%
- 实现风险闭环管理
- 提供AI辅助决策支持

### 2.2 核心设计原则

#### 2.2.1 全面拥抱 SDK
- 使用 SDK 的 `@tool` 装饰器定义工具
- 使用 SDK 的 `create_sdk_mcp_server` 创建 MCP 服务器
- 移除所有手动 XML 解析
- 移除所有规则匹配

#### 2.2.2 动态 Skill 加载
- 自动扫描 `skills/` 目录
- 零配置，自动注册
- 支持即插即用

#### 2.2.3 统一 Agent 核心
- 配置驱动的统一入口
- 消除 Manager/Staff 双类
- 通过 AgentConfig 实例化

#### 2.2.4 自主规划
- 完全信任 SDK 的 ReAct 循环
- 移除所有人工干预
- 移除所有预设流程

## 三、功能需求（基于新架构）

### 3.1 核心功能

#### 3.1.1 用户管理
- **用户登录**: 支持多个用户选择登录，角色卡片式选择界面
- **角色区分**: 业务负责人 vs 一线人员
- **用户切换**: 支持快速切换用户身份（顶部个人中心）
- **权限控制**: 根据角色显示不同工作区
- **地区归属**: 用户归属特定地区（总部/上海区/北京区/山西区/浙北区）
  - 总部用户可切换查看全地区数据
  - 地区用户默认只能看自己地区数据

#### 3.1.2 风险数据管理（业务负责人）

**数据视图切换**:
- 日度数据 Tab - 查看每日风险明细
- 月度数据 Tab - 查看月度汇总数据

**风险数据列表**:
- 表格展示所有风险数据
- 支持分页（5/10/20/50/100条/页）
- 支持全选/多选
- 支持按列排序
- 风险等级可视化（高/中/低）

**数据筛选**:
- 全局搜索：搜索风险明细和任务
- 地区筛选：根据用户地区自动筛选
- 字段筛选：按指定字段精确搜索

**风险统计看板**:
- 高风险数量统计
- 中风险数量统计
- 低风险数量统计

**数据来源**:
- 日度数据：从 `data/risk_data_*.csv` 文件加载
- 月度数据：从 `data/risk_data_monthly_*.csv` 文件加载

**数据字段**:
- 运单号
- 发货地/收货地
- 揽收人/揽收人ID
- 客户名称/供应商名称
- 货物类型/产品类型
- 重量/体积
- 运费金额/结算金额
- 发货时间/揽收时间/派件时间/签收时间
- 运单状态
- 对账人
- 公里数
- 发货网点/收货网点
- **异常类型**: 超时派送、虚假签收、重量异常、包装破损等
- **风险等级**: 高/中/低

#### 3.1.3 任务管理

**任务列表（业务负责人）**:
- 显示所有创建的任务
- 支持按状态筛选：已创建/已下发/反馈完成/已超期
- 支持按类型筛选：日度任务/月度任务
- 显示任务基本信息：
  - 任务ID
  - 风险简述
  - 状态
  - 执行人
  - 创建时间
- 任务区域可折叠

**任务详情**:
- 完整任务信息
- 反馈总结
- 上传文件列表
- 聊天历史

**任务创建**:
- 通过对话方式创建
- 支持指定执行人
- 关联风险数据
- 自动生成任务ID

**任务状态流转**:
```
已创建 → 已下发 → 反馈中 → 反馈完成
                ↓
             已超期
```

#### 3.1.4 AI智能体对话（基于 SDK）

**对话功能**:
- 实时对话界面
- 消息历史保存
- 支持文本消息
- 支持文件上传
- SSE实时事件推送

**初始对话体验**:
- 欢迎语 + 功能引导
- 快捷功能卡片入口：
  - 今日风险分析
  - 月度重点风险分析
  - 任务下发统计
  - 创建自定义任务

**AI能力（业务负责人）**:
- 风险数据分析
- 文件解析（CSV、Excel、PDF、Word）
- 执行人推荐
- 任务创建指导
- 报告生成

**AI能力（一线人员）**:
- 任务推送
- 核查指导
- 文件内容验证
- 反馈总结生成
- 问题解答

**Staff Agent 核心职责说明**:

Staff Agent 是被 Manager Agent 调用的，它的职责是：
1. **任务下发**：当Manager创建风险核查任务后，主动给一线用户发送任务通知，告知需要提交什么材料
2. **材料审核**：一线用户提交材料后，进行双重判断：
   - 判断材料是否符合任务要求（完整？涵盖所有内容？）
   - 判断风险是否真实存在（真实风险？问题不大？无风险？）

**重要**：Staff Agent 不是"指导员"教一线人员如何核查风险，而是"传话筒"传达任务要求 + "材料审核员"审核材料和风险。

**AI工具**:
- `parse_csv`: 解析CSV文件
- `parse_excel`: 解析Excel文件
- `parse_pdf`: 解析PDF文件
- `parse_word`: 解析Word文件
- `read_risk_data`: 读取风险数据
- `list_users`: 列出用户
- `get_task_status`: 查询任务状态
- `get_task_detail`: 获取任务详情
- `create_task`: 创建任务
- `update_task_status`: 更新任务状态
- `assign_task`: 分配任务

#### 3.1.5 文件管理

**文件上传**:
- 支持拖拽上传
- 支持点击上传
- 支持的格式：PDF、JPG、PNG、DOCX、DOC
- 文件大小限制：单文件 < 50MB

**文件存储**:
- 路径: `data/uploads/{task_id}/{filename}`
- 文件信息记录到 `data/feedback/{task_id}.json`

**AI文件处理**:
- PDF: 提取文本内容（前3页）
- Word: 提取段落文本
- 图片: 显示基本信息

#### 3.1.6 反馈管理

**反馈内容**:
- 聊天历史
- 上传文件列表
- 反馈总结（AI生成）
- 任务状态
- 时间戳

**反馈保存**:
- 路径: `data/feedback/{task_id}.json`
- 实时保存每次对话
- 刷新页面可恢复历史

### 3.2 辅助功能

#### 3.2.1 布局管理（业务负责人）
- **三栏布局**:
  - 左侧：风险数据 + 任务列表（可调整宽度、可折叠）
  - 中间：AI对话区（主区域）
  - 右侧：任务详情（可调整宽度、可折叠/展开）
- **拖拽调整**: 支持左右拖拽调整栏宽
- **响应式**: 适配不同屏幕尺寸

#### 3.2.2 分页组件
- 显示总数据量
- 支持自定义每页条数
- 页码快速跳转
- 上一页/下一页
- 页码省略显示（超过5页时）

#### 3.2.3 错误处理
- 网络错误提示
- 文件上传失败提示
- Agent调用失败降级
- 友好的错误信息

## 九、风险评估

### 9.1 技术风险
- **风险**: AI SDK依赖不稳定
- **缓解**: 添加降级机制，提供简化模式

- **风险**: 文件上传安全性
- **缓解**: 格式校验、大小限制、病毒扫描

- **风险**: 并发访问问题
- **缓解**: 会话管理、文件锁

### 9.2 业务风险
- **风险**: 用户不接受AI建议
- **缓解**: 提供人工审核、快速覆盖

- **风险**: 任务分配不合理
- **缓解**: 支持手动调整执行人

### 9.3 运营风险
- **风险**: 数据丢失
- **缓解**: 定期备份、数据导出

- **风险**: 系统宕机
- **缓解**: 健康检查、自动重启
