# 左侧栏导航功能 - 需求与方案总结

## 需求理解

### 1. 功能目标
将原有的"日度数据/月度数据"Tab切换改为**侧边栏导航**，点击后整个左边栏内容刷新。

### 2. 导航结构
```
左侧边栏
├── 总览    → 只显示统计图表，无下发任务
├── 日度数据 → 风险明细表格 + 下发任务
└── 月度数据 → 风险明细表格 + 下发任务
```

### 3. 总览页面统计内容
- 今日风险数据柱状图（高/中/低）
- 本月风险数据柱状图（高/中/低）
- TOP 5 风险客户(日度) - 堆叠条形图
- TOP 5 风险客户(月度) - 堆叠条形图
- 日度任务统计 - 柱状图
- 月度任务统计 - 柱状图

### 4. 关键交互
- 点击侧边栏菜单 → 整个左侧内容区域刷新
- 总览页面 → 不显示下发任务卡片
- 日度/月度页面 → 显示风险明细 + 下发任务

## 技术方案

### 1. 状态管理
- 使用 `dataTab` 状态管理当前选中的导航项：'overview' | 'daily' | 'monthly'
- 根据 `dataTab` 值渲染不同的内容区域

### 2. 统计计算
- `dailyRiskStats`: 日度风险高/中/低数量
- `monthlyRiskStats`: 月度风险高/中/低数量
- `top5DailyCustomers`: 日度TOP5客户（按风险等级堆叠）
- `top5MonthlyCustomers`: 月度TOP5客户
- `dailyTaskStats`: 日度任务各状态数量
- `monthlyTaskStats`: 月度任务各状态数量

### 3. 条件渲染
- 总览页面：只显示统计图表，不显示搜索框下方的高/中/低风险数量统计
- 日度/月度页面：显示完整的风险明细表格 + 下发任务列表

## 失败经验教训

### 1. 代码结构问题
- App.jsx 文件超过1500行，结构复杂
- 多次条件嵌套导致 `</>` (Fragment) 和 `)}` (条件判断) 匹配混乱

### 2. 错误类型
```
Expected ")" but found "{"
Unterminated regular expression
```
- 原因：在条件渲染 `{dataTab !== 'overview' && (...)}` 中，Fragment `<>...</>` 没有正确闭合
- 位置：风险明细数据表格结束后，任务列表section之前

### 3. 修复建议
- 将左侧栏内容拆分为独立组件（OverviewPage, DailyPage, MonthlyPage）
- 或使用更清晰的JSX结构，避免深层嵌套
- 在修改前先备份 working 版本

### 4. 后续建议
- 使用 `{'{'}` + `map` 或独立组件来避免大量条件嵌套
- 考虑使用 React Router 或状态管理库来管理页面切换
- 单元测试覆盖关键交互
