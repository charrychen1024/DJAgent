# DJAgent 智能体集成开发计划

## 背景

DJAgent 项目是一个风控管理工具，有前端（React）+ 后端（Flask）。项目已包含 Claude Agent SDK 集成的代码（`staff_agent.py`, `manager_agent.py`），但后端 API 接口未实际调用 Agent，仍使用关键词规则匹配回复。

## 需求

### 1. 真实 AI 对话
- 每次用户发消息，都是真实的 Agent（大模型）回复
- 不是关键词触发，而是每次都调用 Agent

### 2. 会话隔离与复用
- 不同用户之间会话隔离（A 和 B 看不到对方对话）
- 同一用户会话持续复用（多次对话，上下文保持）

### 3. 任务流程
- 主Agent（业务负责人）创建任务 → 写入 tasks.csv
- 一线人员打开任务 → 子Agent读取任务 → 智能推送任务信息
- 一线人员与子Agent对话 → Agent 指导核查工作

## 技术方案

### 框架问题
- Flask（同步） vs Agent SDK（异步）
- **方案**：用 `asyncio.run()` 包装异步调用（快速实现，后续迁移 FastAPI）

### 会话管理
- 创建 `session_manager.py` 维护用户 → Agent 实例映射
- 同一 user_id 复用同一 Agent 实例

## 开发计划

### Step 1: 创建会话管理器
**文件**: `backend/agents/session_manager.py`

- `get_or_create_agent(user_id, user_name, role)` — 获取或创建 Agent
- `get_agent(user_id)` — 获取已有 Agent
- `close_agent(user_id)` — 关闭会话

### Step 2: 改造子Agent对话接口

#### 2.1 获取对话历史
**接口**: `GET /api/tasks/<task_id>/chat-history`

- 调用 `StaffAgent.init_task(task_id)` 获取任务信息
- Agent 生成智能推送消息（而非固定文本）

#### 2.2 发送消息
**接口**: `POST /api/tasks/<task_id>/message`

- 从会话管理器获取/创建 StaffAgent
- 调用 `agent.chat(message)` 获取真实回复
- 保存对话到文件

### Step 3: 改造主Agent对话接口

**接口**: `POST /api/chat`（业务负责人使用）

- 从会话管理器获取/创建 ManagerAgent
- 调用 `agent.chat(message)` 获取真实回复

### Step 4: 测试验证

- 启动 Flask 服务
- 测试不同用户会话隔离
- 测试同一用户上下文保持
- 验证 Agent 真实回复
