## 一、测试概述

### 1.1 测试目标
- 验证所有核心功能是否符合PRD需求
- 确保前后端接口正常工作
- 验证AI智能体对话功能
- 测试文件上传和处理
- 验证任务全流程（创建→下发→核查→反馈）
- 测试多用户协同工作场景

### 1.2 测试范围

| 模块 | 测试内容 | 优先级 |
|-----|---------|-------|
| 用户管理 | 登录、角色区分、用户切换 | P0 |
| 风险数据展示 | 数据加载、分页、筛选、排序 | P0 |
| AI对话 | 业务负责人对话、一线人员对话 | P0 |
| 任务管理 | 创建、下发、状态跟踪、详情查看 | P0 |
| 文件上传 | 上传、解析、验证、保存 | P0 |
| 反馈管理 | 聊天历史、反馈总结、状态更新 | P1 |
| 接口测试 | API健康检查、数据接口、错误处理 | P1 |
| 集成测试 | 端到端流程测试 | P1 |

### 1.3 测试环境

**环境配置：**
- 操作系统：macOS / Linux / Windows
- Python版本：3.11
- Node.js版本：18+
- 浏览器：Chrome / Firefox / Safari / Edge

**依赖服务：**
- 后端服务：`uvicorn app_fastapi:app --host 127.0.0.1 --port 5005`
- 前端服务：`npm run dev` (通常在 http://localhost:5173)
- AI SDK：claude-agent-sdk
- 环境变量：`.env` 文件配置
