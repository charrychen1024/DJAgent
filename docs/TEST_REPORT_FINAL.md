## 完整状态流转图

```
Manager 创建任务
      ↓
    已创建 (可选中间状态)
      ↓
    已下发 (create_task 默认状态)
      ↓
    反馈中 (Staff首次消息时自动转换)
      ↓
   /    \
  ↓      ↓
反馈完成   已超时
(用户确认) (系统判断)

异常情况:
  已下发 → 下发失败 (分配异常时)
```

## 状态说明汇总

| 状态 | 说明 | 触发条件 |
|------|------|----------|
| 已创建 | 任务刚创建 | Manager 创建任务 |
| 已下发 | 任务已下发给执行人 | create_task 成功 |
| 反馈中 | 执行人正在处理 | Staff 首次消息 |
| 反馈完成 | 执行人确认完成 | Staff 调用 update_task_status |
| 已超时 | 超过截止时间未完成 | 系统检查 (反馈中状态超过 deadline) |
| 下发失败 | 任务发送/分配失败 | assign_task 异常 |
