# 风险分析 Skill

## 概述

这是一个专业的风险分析技能，帮助管理者分析风险数据、识别异常模式、评估风险等级，并提供决策建议。

## 功能能力

### 1. 数据解析与加载
- 解析 CSV 格式风险数据
- 解析 Excel 格式风险数据
- 按地区筛选风险数据
- 按时间范围筛选数据

### 2. 风险模式识别
识别以下风险模式：
- **超时风险**：派送超时、签收延迟
- **重量异常**：货物重量与记录不符
- **虚假签收**：签收信息异常
- **区域异常**：非正常区域配送
- **数量异常**：配送数量与记录不符

### 3. 风险等级评估
- 高风险：多条严重违规记录
- 中风险：偶发异常但影响较大
- 低风险：轻微异常或边缘情况

### 4. 分析报告生成
- 风险数据统计摘要
- 风险类型分布图表
- 趋势分析预测
- 针对性改进建议

## 使用场景

### 适用场景
- 用户要求分析风险数据
- 用户想了解某个地区或时段的的风险情况
- 用户需要识别异常模式和趋势
- 用户想要专业的风控建议

### 不适用场景
- 用户只想查看现有任务（使用 list_tasks 工具）
- 用户想创建新任务（使用 task-creator skill）
- 用户想推荐执行人（使用 receiver-recommender skill）

## 处理流程

```
1. 解析用户请求
   └── 提取：数据类型、时间范围、地区筛选

2. 加载风险数据
   └── 读取 data/risk_data_*.csv
   └── 按条件筛选

3. 数据分析
   └── 统计风险类型分布
   └── 识别异常模式
   └── 计算风险等级

4. 生成报告
   └── 汇总统计数据
   └── 列出风险模式
   └── 给出改进建议

5. 返回结果
   └── JSON 格式分析报告
```

## 系统集成

### 使用的工具
- `read_risk_data` - 读取风险数据文件
- `parse_csv` - 解析 CSV 文件
- `list_users` - 获取可选的执行人列表
- `get_risk_data_summary` - 获取风险数据摘要

### 数据来源
- 日度风险数据：`data/risk_data_daily_*.csv`
- 月度风险数据：`data/risk_data_monthly_*.csv`
- 风险统计：`data/risk_summary.csv`

### 角色要求
- 仅 Manager 角色可用
- 需要数据读取权限

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 数据文件不存在 | 返回提示信息，列出可用数据文件 |
| 数据解析失败 | 返回解析错误详情 |
| 无风险数据 | 返回"未发现风险数据"提示 |
| 筛选条件无效 | 默认返回全量数据 |

## 最佳实践

1. **先了解数据范围**：确认用户想分析的时间范围和地区
2. **提供统计摘要**：用数字说话，让用户快速了解整体情况
3. **给出具体建议**：不仅分析问题，还要给出可操作的建议
4. **引用具体案例**：在建议中引用具体的问题订单，增加说服力
5. **结合业务场景**：考虑物流行业的实际业务流程和约束
