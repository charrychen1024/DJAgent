# 核查指导 Skill

## 概述

这是一个专门为一线员工设计的核查指导技能，帮助员工了解任务要求、掌握核查步骤、准备所需材料，并顺利完成风险核查工作。

## 功能能力

### 1. 任务信息解读
- 解析任务详情和风险描述
- 说明任务类型（日度/月度）
- 告知截止时间和紧急程度

### 2. 核查步骤指导
提供标准化的核查流程：
- **第一步**：核实运单信息与风险描述是否一致
- **第二步**：检查相关单据和凭证
- **第三步**：如实记录核查结果
- **第四步**：上传相关证明材料（照片、凭证等）
- **第五步**：提交核查反馈

### 3. 材料准备指导
根据任务类型说明需要准备的材料：
- **运单凭证**：发货单、签收单等
- **称重记录**：如果涉及重量异常
- **照片/视频**：问题现场或证据照片
- **文字说明**：具体情况描述

### 4. 常见问题解答
- 如何进行称重？
- 需要拍什么照片？
- 文字说明怎么写？
- 如何提交反馈？

### 5. 注意事项提醒
- 材料清晰可读的要求
- 如实记录的重要性
- 提交后的查看方式

## 使用场景

### 适用场景
- 员工刚收到任务，不知道从何做起
- 员工遇到具体问题需要指导
- 员工不确定需要准备什么材料
- 员工想了解任务截止时间

### 不适用场景
- Manager 角色使用（此技能仅限 Staff）
- 用户想要创建或分配任务
- 用户想要分析数据
- 单纯的闲聊

## 处理流程

```
1. 解析请求
   └── 提取任务ID或问题内容

2. 获取任务信息
   └── 调用 get_task_detail 获取任务详情
   └── 获取风险数据摘要
   └── 查看已提交的反馈内容

3. 生成指导内容
   └── 根据任务类型构建步骤
   └── 列出所需材料
   └── 添加针对性问题回答

4. 返回指导
   └── 返回结构化的指导内容
```

## 系统集成

### 使用的工具
- `get_task_detail` - 获取任务详情
- `get_risk_data` - 获取风险数据摘要
- `list_uploaded_files` - 查看已上传文件
- `submit_feedback` - 提交核查反馈

### 数据来源
- 任务信息：`data/tasks.csv`
- 风险数据：`data/risk_data_*.csv`
- 反馈记录：`data/feedback/{task_id}.json`

### 角色要求
- 仅 Staff（员工）角色可用
- 需要能读取自己的任务

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 任务ID无效或不存在 | 返回"未找到任务，请确认任务编号" |
| 任务不属于该员工 | 返回"您没有权限查看此任务" |
| 任务已完成 | 提示"此任务已完成，可在任务列表查看" |
| 获取详情失败 | 返回"获取任务信息失败，请稍后重试" |

## 最佳实践

1. **主动提供完整信息**：不要等员工问，而是主动告知任务要求
2. **步骤清晰可执行**：每个步骤都要具体可操作
3. **材料清单明确**：清楚列出需要准备什么
4. **强调关键要点**：如"如实记录"、"清晰照片"
5. **提供后续支持**：告知有疑问可以继续提问
